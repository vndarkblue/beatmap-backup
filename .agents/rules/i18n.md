# Internationalization (i18n) Rules

Ứng dụng hỗ trợ hoàn chỉnh 3 ngôn ngữ: Tiếng Anh (`en`), Tiếng Việt (`vi`), và Tiếng Nhật (`ja`). Tính nhất quán giữa các bộ từ điển ngôn ngữ được kiểm tra bằng bài test tự động gắt gao trong bộ test suite.

## 1. Nguyên Tắc Bắt Buộc Khi Thêm / Sửa Chuỗi UI

1. **Tuyệt đối không hardcode text hiển thị**:
   - Mọi chuỗi văn bản trên giao diện người dùng (nhãn nút, tiêu đề, mô tả, thông báo lỗi, toast) bắt buộc phải qua hàm dịch `t('key')` hoặc `$t('key')`.
2. **Quy tắc Tam Giác Ngôn Ngữ (Strict Parity)**:
   - Khi thêm hoặc chỉnh sửa một khóa (key) dịch, **bắt buộc phải cập nhật đồng thời ở cả 3 file**:
     - `src/renderer/src/i18n/locales/en.json`
     - `src/renderer/src/i18n/locales/vi.json`
     - `src/renderer/src/i18n/locales/ja.json`
   - Nếu chưa có bản dịch tiếng Nhật hoặc tiếng Việt chuẩn xác, tạm thời điền bản dịch tạm hoặc chuỗi tiếng Anh, nhưng **tuyệt đối không được bỏ trống hoặc thiếu key**.
3. **Tính Nhất Quán Về Biến / Placeholder**:
   - Mọi placeholder nội suy dạng `{ten_bien}` (ví dụ `{count}`, `{percent}`, `{path}`) phải **khớp 100%** giữa cả 3 ngôn ngữ.
   - Sai khác tên biến giữa các ngôn ngữ sẽ khiến bài test `tests/renderer/i18n.test.ts` bị FAIL.

## 2. Tổ Chức Cấu Trúc Khóa (Key Hierarchy)

Các file JSON được tổ chức theo module màn hình / tính năng:

```json
{
  "common": { "ok": "OK", "cancel": "Cancel", ... },
  "nav": { "backup": "Backup", "download": "Download", ... },
  "backup": { ... },
  "download": { ... },
  "filter": { ... },
  "settings": { ... }
}
```

- Không đặt khóa phẳng tràn lan ở cấp root; nhóm theo ngữ cảnh sử dụng.
- Đặt tên khóa theo ngữ nghĩa (semantic key): ví dụ `settings.database.sync_btn` thay vì `btn1`.

## 3. Công Cụ Hỗ Trợ Dịch (Scripts)

Khi cần làm việc với biên dịch viên số lượng lớn:

- **Xuất ra CSV**: `npm run i18n:export`
  - Chạy `scripts/i18n-export-csv.js`, gom toàn bộ khóa từ 3 file JSON thành file bảng tính CSV.
- **Nhập từ CSV**: `npm run i18n:import`
  - Chạy `scripts/i18n-import-csv.js`, đồng bộ lại nội dung từ CSV vào các file JSON tương ứng.

## 4. Kiểm Thử Nhanh Trước Khi Hoàn Thành

Sau khi chỉnh sửa bất kỳ chuỗi i18n nào, chạy ngay:

```powershell
npx vitest run tests/renderer/i18n.test.ts
```

Để đảm bảo:

- Cả 3 ngôn ngữ có cùng số lượng và danh sách key.
- Không có chuỗi nào rỗng.
- Toàn bộ biến nội suy `{placeholder}` hoàn toàn khớp nhau.
